# Book Codebase

A collaborative repository for developing a fictional novel using Git and GitHub.

## Files

- `story.md` – Contains the main storyline of the book.
- `character.md` – Contains character profiles.
- `evidence.md` – Contains Maya's car description.
- `README.md` – Project overview.

## Workflow

1. Create a feature branch.
2. Make one logical change.
3. Commit your work.
4. Open a Pull Request.
5. Address review feedback.
6. Merge once approved.
7. Delete the feature branch.
